# glossary — add-gamedev-skill

- Track A: code/technical work; SDD-style spec folder spec.md+tasks.md+review.md under .gamedev/ (source: gamedev instructions.md §2)
- Track B: creative/design work; live phase docs, no spec folder (source: same)
- Hybrid / Track H: level-designer (LVL-id+changelog) and qa-lead (playtest vs /bug escalate); middle ground (source: instructions.md §2, CONTEXT.md)
- Phase: one of 01-preproduction | 02-production | 03-postproduction; spine linear, agents parallel inside (source: cycle.md)
- Post-production & Launch: skill name for phase 3 (user said "production y launch") (source: SKILL.md cycle)
- Gate: human ✅ required to advance phase; conditional allowed iff debt:gate-* in backlog.md (source: instructions.md §5)
- @director: producer/orchestrator; writes phase/focus; not a dumb router (source: cycle.md)
- state.md agent line: non-idle only; status in_progress|blocked|needs_review|done; blocked carries blocked-by (source: templates/state.md)
- Path-lifecycle: one root_path → one lifecycle chrome; `.gamedev/` present ⇒ Game tab, Specs omitted (source: ADR-001)
- Silent win: if `.gamedev/` exists, gamedev wins with no conflict UI even when `.sdd-skill/` is also there (source: ADR-001 user 2026-08-30)
- Specs tab: existing sdd+grill kanban; must not become the gamedev board (source: user + ADR-006 prior plan)
- Game tab: proposed new workspace tab for .gamedev/ (source: user; types.ts comment already anticipates)
- Game inbox: unconverted grill epics on a `.gamedev/` path, listed on Game tab not Specs (source: ADR-002)
- Artifact card: one existing owned file/folder (phase doc, SYS-*, LVL-*, asset folder, playtest-log, post-prod doc); owning agent visible; no missing-file placeholders (source: ADR-005)
- Unconverted (gamedev): omit from Inbox iff Companion-to exact path on a Game artifact OR roadmap epic-map (cited plan slug + epic-NNN). Plan-folder cite is not enough. No kebab fuzzy. Missing link stays (source: ADR-006)
- Game columns: Inbox | Pre-production | Production | Post-production & Launch (source: ADR-003)
- Work-state: pending | in_progress | done (+ blocked) on the card; not a board axis; many in_progress in one phase (source: ADR-003 user 2026-08-30)
- Skill confirmation: advancing work-state / tasks / specs happens only by running gamedev-skill as the owning agent; Track B/manuals wait on doc header stamp, not Gherkin (source: ADR-004, _core.agent §4)
- Game archive: CBM-owned hide of already-done cards; never writes `.gamedev/` (source: ADR-004; same split as spec_archive)
- Game expand: in-card grow like Specs; Track A blurb+tasks.md; Track B header only; grill summary; Archive on done artifacts not inbox (source: ADR-007)
- Gamedev ADR trio: `.gamedev/game_context.md` + `baseline/TECH_STACK.md` + `baseline/ARCHITECTURE_ADR.md`; silent-win replaces sdd trio; no merge (source: ADR-008)
- Game how-to: map not launcher; chrome `continue`; card copies `continue @<owning-agent>`; inbox copies `continue`; no CBM invoke (source: ADR-009)
- Game deps: state.md blocked-by on that agent’s cards + board blocked strip; Track A expand shows spec Inputs; no roadmap graph (source: ADR-010)
- skill-presence: existing GET /api/skill-presence {sdd_skill, gamedev_skill}; unused by graph-ui today (source: http_server.c, useSddSkillPresent.test)
