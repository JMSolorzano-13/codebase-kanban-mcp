# glossary — executive-ui-ia

- Dashboard: account-level first screen. Projects list + Control. No per-project Graph/Specs. No Nodes/Edges summary sections. (source: user + inspection of StatsTab)
- Project workspace: second-level UI after entering one project. Default tab Graph. Other tabs: Specs (only if .sdd-skill/), ADR (always). Header shows last indexed/reindex datetime. Future tabs must fit without IA rewrite. (source: user 2026-08-29)
- Path: canonical filesystem repo root that was indexed (root_path). (source: store + UI CreateIndexModal)
- Project: named index of exactly one Path. Name derived from Path. No optional Project ID in the UI create flow. (source: user Q2 2026-08-29, ADR-012)
- Chrome: all UI chrome except the 3D graph canvas — Dashboard, tabs, buttons, Control, headers, modals. Grayscale. (source: user Q1, ADR-011)
- Control: existing ControlTab — daemon/process CPU/RAM, process list, logs. Operational, not project-scoped today. (source: ControlTab.tsx)
- Graph tab: existing 3D knowledge-graph explorer for one selected project. (source: GraphTab.tsx)
- Specs tab: existing sdd-skill Kanban read of .sdd-skill/ under the project root. Hidden when .sdd-skill/ absent (http_server already documents this). (source: user + spec_board.h)
- ADR tab: Phase 1 project-workspace tab. Same store as manage_adr / /api/adr. Human can create and edit by hand. Not on Dashboard. (source: user 2026-08-29)
- ADR auto-fill (Phase 2): separate later scope. On manual reindex only, deterministic parse of sdd-skill project docs into CBM ADR (same class of process as spec_board read and node extraction). No LLM / min tokens. Manual edit remains. (source: user 2026-08-29)
- Phase 2 source trio: .sdd-skill/context_ai.md + baseline/TECH_STACK.md + baseline/ARCHITECTURE_ADR.md only. (source: user Q1 2026-08-29)
- ADR generated region: parse output; replaced on every manual reindex. (source: user Q2)
- ADR manual region: human-edited; parse never writes it. (source: user Q2)
- Manual reindex: user-triggered index_repository / UI Index, not watcher auto-sync. Phase 2 ADR parse runs only here. (source: user; matches sdd-skill codebase-memory.md: reindex is user-only)
- Nodes/Edges sections: current StatsTab aggregate cards + per-project label chips from get_graph_schema. Explicitly out of Dashboard. (source: user + StatsTab.tsx)
- Duplicate-index attempt: new create of a Path or Project that already exists → block + redirect to existing. (source: user)
- Legacy duplicate: already-indexed clash. Show conflict, enter newest, ask auth to delete older; yes deletes older. (source: user Q2 2026-08-29)
- Last indexed: visible datetime of last update/reindex on Dashboard card and workspace header. Backed by existing Project.indexed_at. (source: user + types.ts)
